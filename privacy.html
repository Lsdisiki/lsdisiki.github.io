OpenList-Drive 应用介绍 隐私政策 使用条款

隐私政策

生效日期为 2026 年 11 月 12 日

本政策适用于 OpenList-Drive 个人部署实例及本应用介绍网站。实例部署者负责管理服务器、Google OAuth 客户端和实例用户的访问权限。

访问的数据与用途

在你授予 Google Drive 访问权限后，实例根据所挂载的根目录访问文件夹、文件名称、标识符、大小、修改时间等元数据，以及预览、下载或文件操作所需的文件内容。具备操作权限的用户可发起上传、创建、重命名、移动、复制和删除等请求。

Google OAuth 访问令牌和刷新令牌用于连接已授权的 Google Drive，并在访问令牌过期后继续完成用户请求。本应用将 Google 用户数据用于网盘连接、目录展示和用户请求的文件管理功能。

数据的存储与传输

OAuth 刷新令牌、客户端配置和存储挂载信息保存在部署者管理的 OpenList 服务器中。实例可缓存目录和文件元数据以显示文件列表，文件内容会在预览、下载、上传或其他文件操作过程中传输和处理。实例当前的目录缓存设置为 30 分钟。

浏览器登录状态和偏好设置由实例及浏览器保存。服务器和托管平台可能保留处理请求与排查故障所需的运行日志，具体保留期限由部署者和相应平台管理。

第三方服务与访问权限

Google 按其隐私政策处理登录、授权和 Google Drive API 请求。本实例配置中使用的 Google 授权回调服务可能参与授权码交换和令牌返回。用户应核对 Google 授权页面显示的应用身份、请求范围及回调服务地址。

有权访问实例的用户可按实例设置查看或操作已挂载的文件。能够管理服务器或存储配置的部署者和管理员可接触服务器保存的配置和凭据。部署者应依据实际需要管理这些权限。

应用介绍和政策页面托管于 GitHub Pages，网站访问由 GitHub 处理。本介绍网站使用静态 HTML 和 CSS。第三方平台的数据处理适用其各自政策。

Google 用户数据的使用限制

本应用对从 Google API 接收的信息的使用和传输遵守 Google API 服务用户数据政策，包括其中的 Limited Use 要求。Google 用户数据仅用于本政策披露的用户请求功能。

撤销授权与删除配置

你可以在 Google 账号的第三方应用连接页面撤销本应用的访问权限。撤销后，实例将无法继续使用对应授权获取新的访问令牌。已缓存或已下载的数据需要由部署者或接收该数据的用户另行清理。

部署者可在 OpenList 管理界面删除相应存储挂载，清理授权配置，并管理服务器缓存、日志及备份中的相关副本。需要协助撤销访问或清理实例数据时，请联系实例部署者或 Google OAuth 授权页面显示的用户支持邮箱。

政策更新

当实例的数据访问或处理方式发生变化时，部署者应更新本政策及生效日期。请在授权和使用前查看此页面。
